**Расхождения с документацией и интерфейсом.**

1. Подсветка просрочки и штраф считают срок по-разному. Шаблон `templates/librarian.php:30` помечает строку классом `row-late`, если `strtotime(due_at) < time()`, то есть уже с 00:00 дня срока; штраф начисляется только со следующего дня (`today > due`, `LoanService.php:205`). В C02 строка со сроком D подсвечена как просроченная, а возврат прошёл без штрафа.
2. README (строки 16–17): «Штраф за просрочку — 10 рублей в день (для студентов)». Код совпадает: ставка `FINE_PER_DAY = 10`, преподавателю штраф не начисляется (C05). README не уточняет, что день срока не считается просрочкой — это видно только по коду и C02.
3. Две записи (`UPDATE loans`, `UPDATE copies`) выполняются без транзакции (`LoanService.php:210–214`). В прогоне не наблюдалось, но при ошибке второго запроса выдача окажется закрытой, а экземпляр — выданным.

ID C01–C08 и данные [test-data.sql](test-data.sql) сохраняются для повторного прогона в М09.
