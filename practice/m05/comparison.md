# Сравнение офисных пакетов

Задача выбора: в каком **бесплатном настольном** офисном пакете на рабочем месте студента (**macOS**) вести
документацию проекта — отчёты по шаблону колледжа в `.docx`, которые затем открывает руководитель в Microsoft Word, —
и открывать выгрузки из «Библиотеки КАИТ» (`debtors.csv`). Главное в задаче — чтобы `.docx` после правки в пакете
выглядел у руководителя так же, как у студента.

Рабочее место: MacBook (Apple Silicon, arm64), macOS 26.6, 16 ГБ памяти. Тестовые документы — свои отчёты
`ISPO332_Ivannikov_M03.docx` и `ISPO332_Ivannikov_M04.docx` (оба последний раз сохранены в Microsoft Word).

Расчёт — в `weighted-score.xlsx` в этой папке.

| К7 | бесплатно для колледжа и есть в реестре | бесплатно для колледжа, в реестре нет | платно или нельзя использовать в организации |
