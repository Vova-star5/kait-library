## 4. Зависимости

Файлов зависимостей в проекте нет: сторонние пакеты не используются, всё написано вручную. Поэтому в таблице — встроенные расширения PHP и API браузера, без которых проект не работает.

| Пакет | Версия | Зачем нужен |
|---|---|---|
| PHP | 8.x | язык сервера |
| PDO | встроен в PHP | единый интерфейс к БД, подготовленные запросы (`src/Database.php`) |
| pdo_mysql | встроен в PHP | драйвер MySQL для PDO |
| session | встроен в PHP | хранение входа пользователя (`src/bootstrap.php`, `src/Auth.php`) |
| mbstring | встроен в PHP | длина строк с кириллицей (`mb_strlen` в `src/Validator.php`) |
| json | встроен в PHP | ответы API (`json_encode` в `src/helpers.php`) |
| MySQL / MariaDB | 8 / 10.x | хранение данных |
| Apache | 2.4 | веб-сервер (из XAMPP) |
| Fetch API | браузер | запросы клиента к `api.php` (`public/assets/js/api.js`) |
| FormData | браузер | загрузка обложек книг |

Плюс: нет устаревших пакетов и уязвимостей в сторонних библиотеках. Минус: всё написано вручную, в том числе авторизация, проверка данных и маршрутизация, и именно там находятся основные проблемы.

## 6. Запуск

Шаги, которые реально сработали у меня (Windows 11, XAMPP 8.2.12):

```
winget install --id ApacheFriends.Xampp.8.2 --exact
# проект скопирован в C:\xampp\htdocs\kait-library, запущены Apache и MySQL
cd C:\xampp\htdocs\kait-library
C:\xampp\mysql\bin\mysql -u root -e "CREATE DATABASE kait_library CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
C:\xampp\mysql\bin\mysql -u root --default-character-set=utf8mb4 kait_library -e "source database/schema.sql"
C:\xampp\mysql\bin\mysql -u root --default-character-set=utf8mb4 kait_library -e "source database/seed.sql"
# открыть http://localhost/kait-library/public/
```

Файл `.env` создавать не пришлось: значения по умолчанию в `config/config.php` подходят для XAMPP. Проверен вход под `librarian@kait20.ru` (пароль из `seed.sql`), панель выдачи и список должников работают.

Проблемы при запуске и как решили:

- По README в базе создаётся только структура: после `schema.sql` в таблицах `users` и `books` 0 записей, каталог пуст и войти некем. Шага с `seed.sql` в README не было — инструкция дополнена (коммит «docs: дополнена инструкция запуска»).
- В README не указаны тестовые логин и пароль, они есть только в комментарии `seed.sql` — добавлены.
- `schema.sql` заявляет MariaDB 10.6+, но в XAMPP версия 10.4.32; проект с ней работает.

## 7. Вывод о проекте

Проект небольшой и понятный: 1840 строк кода, 7 таблиц, чёткое разделение на страницы, API, сервисы и шаблоны, запускается за несколько минут. По зрелости это учебный прототип, а не готовый продукт: разработка шла 3,5 месяца и остановилась в мае 2025 года, нет тестов, тегов, Pull Request и менеджера зависимостей, фактор автобуса равен 1. Документация расходится с кодом: нет шага с `seed.sql`, не описан летний режим выдачи (`src/LoanService.php:89`), а штраф считается по-разному — 10 рублей в `config/config.php:47` и 15 рублей в `src/ReportService.php:26`, на странице должников 600 дней дали 9000 рублей. Ошибка есть и в лимите: условие `>` в `src/LoanService.php:48` позволяет студенту взять шестую книгу.

Самые вероятные проблемы — безопасность. В поиске значения подставляются прямо в SQL (`src/BookRepository.php:14,17,19`), пароли хранятся в md5 (`src/Auth.php:37`), выдать книгу может любой вошедший пользователь (`public/api.php:74`), отменить можно чужую бронь (`public/api.php:69`), а имя загружаемого файла не проверяется (`public/api.php:112`). Проверка группы есть только на клиенте (`templates/register.php:23`), а категорию «преподаватель» пользователь выбирает при регистрации сам. Начинать ревью стоит с `public/api.php`, `src/LoanService.php` и `src/BookRepository.php`.
